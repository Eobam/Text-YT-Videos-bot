This is supposed to be a YouTube bot that takes videos and texts them to you. 

I made it because I have an Apple Watch, not a phone, so I can't watch YouTube on the go without this.

Include your country code with phone number, you must also have an Apple account connected 

Instructions:
(You must have Python 3, yt_dlp and movie_py installed)
Run the following commands:


git clone https://github.com/Eobam/Text-YT-Videos-bot

cd Text-YT-Videos-bot

python main.py

After you do the following, the video should appear in you iMessages (which you need to have open btw) drag the video into the send thing, and resend it. It then should send after 5-15 minutes depending on size.
